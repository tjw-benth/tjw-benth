# Hi, I'm Tom (@tjw-benth)

Marine benthic ecologist at Åbo Akademi University, Finland. I study how seafloor communities respond to environmental change, mostly through experimental work, trait-based modelling, and spatial analysis. Field sites from the Arctic to the North Sea; analytical home in R.

## What I work on

- **Trait-based ecology** — bioturbation potential, functional diversity, and how individual variability shapes ecosystem processes. Building [BenthoTraitR](https://github.com/tjw-benth/BenthoTraitR), an R package for probability-density trait analysis
- **Multi-stressor experiments** — mesocosm studies crossing multiple anthropogenic stressors (e.g., climate change, offshore wind farm pressures, bottom fishing etc)
- **Spatial ecology** — mapping community and functioning metrics and linking it to carbon cycling
- **Extinction modelling** — simulating biodiversity loss cascades and co-extinction dynamics in benthic communities

## Side projects

Outside the day job I build things for fun. A meal-planning PWA to replace Mealime. A portfolio site. A running/exploration app concept called Slingshot (drop a pin, explore freely, snap back with scenic route options). I like making things that work and putting them in front of people.

## Tech

R is the primary tool (GLS/nlme, gllvm, brms, vegan, emmeans, sf/terra). Git for everything. Obsidian for thinking. I also build web apps (React, Vite, Tailwind) and deploy on Vercel and Cloudflare Pages. Python when the job calls for it. Copilot/Claude Code for the glue in between.
